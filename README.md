# Exercícios de Python

Exercícios de Python desenvolvidos ao longo do primeiro semestre do curso de Ciências da Computação. Organizado por assunto, do mais básico ao mais avançado.

## Estrutura

```
01_basico_listas/              Listas, laços e lógica básica
02_funcoes/                    Funções
03_validacao_try_except/       Validação de entrada com try/except
04_dicionarios/                Dicionários
05_sets_tuplas_comprehension/  Sets, tuplas e list comprehension
06_miniprojetos/                Programas mais completos, combinando vários conceitos acima
```

Arquivos com prefixo `demo_` são material de referência de sintaxe, não exercícios resolvidos.

## Sobre este repositório

Material em revisão contínua: arquivos antigos são reescritos conforme novos conceitos são aprendidos, mantendo o histórico de commits como registro da evolução.
